r-ui

A design-system family for Tailwind v4 and React 19: a token and theme contract, the components built on it, and a renderer that turns JSON written by a model, a CMS or a backend into those components while it streams.

Component showcase

Every component in every state, plus a dashboard, a marketing page and stress cases. Switch theme, density and input from the View panel.

@batthewz/r-ui-react-components {{showcase-version}}

ViewSpec playground

Write a ViewSpec document and see it render, replay it as a stream, and read the validator's issues as you type.

@batthewz/r-ui-renderer {{playground-version}}

Packages

  • @batthewz/r-ui-css: the tokens, the four sizing axes and example themes, as Tailwind v4 CSS. No JavaScript.
  • @batthewz/r-ui-tw-merge: cn(), a tailwind-merge that knows the r-ui utility names.
  • @batthewz/r-ui-react-components: the React 19 components.
  • @batthewz/r-ui-renderer: renders and validates ViewSpec documents.
