# @batthewz/r-ui-renderer

Renders ViewSpec documents (JSON written by a model, a CMS or a backend) as `@batthewz/r-ui-react-components`, whole or while they stream, and validates them anywhere without React: in the browser, on a server, or from the `r-ui-validate` command line. The format is described in [VIEWSPEC.md](./VIEWSPEC.md). This package is pre-release; its guide is still to be written.
